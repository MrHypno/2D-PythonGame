# Save the King!

- The character can be controlled using the W, A, S, D keys, the arrow keys, and a controller
- Click the left mouse button or SPACE key to attack
- Press the TAB key to view the map
- You can use the E key to interact with the chest, the merchant, and the villager dialogues
- While in the inventory, you can use the items associated with keys 1, 2, and 3
- Press ESC to pause the game
- Controller support is available for all actions, even if it isn't explicitly mentioned; I just don't know which buttons they correspond to. Therefore, I can't guarantee that it works.

## Condition of winning or losing
- If you manage to reach the castle or the guards' area before the king dies, you win
- If the king or you dies along the way, you lose
- If you give the wrong answer to the riddle the guards ask, they will turn hostile towards you
